前同事实现已在库（截至 bf5344d3），但 e2e 报告的「✅」大量只核对了外壳。本文是
负责人审计后的问题清单、交互裁决与分批计划，后续 batch 以本文为准。

## 0. 目标线（用户 2026-11-09 裁决）

内测可交付：企业 owner / 企业成员 / 个人空间三种身份，在真实应用端到端走通
进组织 → 进项目 → 聊天 → 项目文件 → 成员 → 项目设置 → 我的应用保存/发布/撤回；
无阻断 bug；空态/报错/权限边界有处理；UI 按设计系统打磨。staging 才能验的

每批由负责人审 diff、跑测试、真实应用验收后提交到各自分支，不 push、不合并。

## 1. 审计结论（一句话版）

1. **项目 Tab 只是外壳**：所有项目 Tab 共用一套导航，切 Tab 只换了左栏列表，
   对话区还是上个项目的会话，发出去的消息进了别的项目（隔离级缺陷）。
2. **企业空间的隐藏「Polo 助手」Tab 还有 7 类入口**（关最后一个项目 Tab、⌘N、
   菜单新建、通知、深链、⌘1、助手类设置），进去就是全部会话 + 建会话失败。
3. **成员面板全功能不可用**：面板把 UI 字段 `viewerRoleHint` 塞进 strict RPC 入参，
   server-core 直接拒收；修好后传输层还会把所有 `prj_*` 错误码抹成通用错误。
4. **「我的应用」从未走通**：项目会话里画布路径校验按旧根推算 → 渲染/保存/固定全失败；
   自己的应用拿 MemberApp.id 去查实例 → 打不开；包里缺 `polo-app.json` → 成员装不上；
   发布后按 publishedEntryId 关联 → 徽标和撤回按钮消失；个人空间列表恒空。
5. **首页**：项目卡第 3 张起布局塌陷（响应式 `block` 盖掉 `flex`）；个人空间仍有
   项目区和创建按钮（违背 Q1）；工具栏和它过滤的网格被「我的应用」隔开，空态叠加。
6. **左栏仍是通用工作区导航**（数据源/技能/自动化是工作区全局数据，违背 Q13/J-5），
   其中编辑浮层与自动化在企业空间建会话必然失败；项目身份、设置入口不在左栏。
7. **项目设置只在首页卡上**，保存后已打开的项目 Tab 仍用旧名/旧指令。
8. **从未端到端验证**：项目文件上传（本地无对象存储与索引）、我的应用全旅程、
   成员账号视角、个人空间。
9. **数据层只落实一半**：session.jsonl 已按项目分存，但 Pi 转录与运行产物仍写旧根
   → 删除的项目会话重启复活、Pi 项目会话分支必失败；项目指令只在建会话时拍快照
   （Claude 后端从不注入）；企业会话仍读个人 AGENTS.md / 个人数据源 / 个人 skills；
   CREATE 不校验项目成员；Agent 会话工具与分支可跨项目。
10. **e2e 实例污染真实 workspace**：workspaces 根写死 `~/.polo-ai`，隔离实例的测试
    会话落进了真实 `my-workspace`（不猜删，待用户确认清理）。

审计原文（含 path:line 证据）由 5 个只读审计产出，要点已并入 §3 各批次。

## 2. 交互与产品裁决（负责人拍板，用户已授权）

| # | 事项 | 裁决 |
|---|---|---|
| R1 | 项目 Tab 的导航模型 | 保留单例导航，补「项目维度」：每个项目记住自己的路由；不变式「项目 Tab 激活时，选中会话必属于该项目，否则落该项目空态」由 NavigationProvider 一处兜底。不做每 Tab 一个 AppShell |
| R2 | 进入项目的落点 | 该项目上次选中的会话 → 最近会话 → 项目空态 |
| R3 | 「新建会话」 | 企业项目内 = 进入项目空态（零写入，首发才建会话），不再落盘空会话。存量空会话不删 |
| R4 | 企业空间的 Polo 助手 | 企业空间 openTabs 不含 Polo Tab。⌘N/菜单新建：在项目 Tab → 本项目空态；在其他 Tab → 打开最近访问项目的空态；无项目 → 回首页并提示「先创建或进入一个项目」。通知/深链按会话 projectId 打开对应项目 Tab |
| R5 | 关闭项目 Tab | 一律回首页，不跳相邻项目；不停止该项目运行中的会话 |
| R6 | Tab 顺序与快捷键 | 新项目 Tab 追加到末尾；⌘1 = 首页，⌘2… 依可见 Tab；图标用文件夹类而非地球 |
| R7 | 项目 Tab 左栏（企业） | 头部：项目名 + 用途一行 + 成员头像/人数（开成员面板）+ 设置齿轮（开项目设置）+「新建会话」；下方保留项目内会话筛选（全部/状态/已标记/已归档/标签）。移除数据源、技能、自动化、工作区设置等工作区全局入口。个人空间不变 |
| R8 | 项目设置入口 | 只在项目 Tab 左栏头部；首页卡片去掉设置按钮（卡片只有「进入」一个动作）。成员可打开只读视图看指令全文 |
| R9 | 项目指令生效范围 | 按 Q12「注入该项目所有会话」：发送时由服务端取项目当前 name/purpose/instructions（短 TTL 缓存，取不到退回会话快照），已有会话下一次发送即生效；Claude 后端补注入 |
| R10 | 企业会话的个人上下文 | 企业会话不读个人 AGENTS.md、不继承个人默认工作目录/数据源/个人 skills；composer 不显示「在此文件夹中工作」。项目级 MCP（Q13-2）本轮不做，列边界 |
| R11 | 项目角色与权限 | 统一称呼「负责人/管理员/成员」，组织侧写「组织管理员」。只有负责人能授予/撤销/移除负责人；管理员管成员。自行退出本轮不做（找负责人移除） |
| R12 | 被移出项目 / 项目不可访问 | 项目列表加载后对账：已不在列表的项目 Tab 关闭并 toast「你已不在项目 X 中」；读写遇 prj_not_found 同样收口。服务端 CREATE/发送校验成员资格 |
| R13 | 项目重名 | 允许（卡片靠用途区分），本轮不加冲突码 |
| R14 | 我的应用 | 以 myapps:list 为唯一来源（计数=列表）。已发布应用留在「我的应用」，显示「已发布」徽标与「撤回」；发布者本人的 space 行在「应用」区不重复显示。发布前确认弹窗。保存幂等（同一会话同一画布再次保存 = 新版本而非新副本）；支持删除。手动上传 HTML 本轮不做 |
| R15 | 首页信息架构（企业） | 页头「首页」→ 我们的项目 → 已固定画布 → 应用（工具栏 + 共享网格紧邻）→ 我的应用。个人空间无项目区。空态合并：两类应用都空时只显示一个空态 |
| R16 | 管理技能入口 | 放回首页「应用」区标题右侧的次要按钮（原助手卡已退役） |
