## 已知边界与判定

- 普通 HTML 的本地相对资源（例如 `./image.png`、外部本地脚本）暂不支持；测试基础能力使用全内联 guide.html。不要把此限制误记为已支持，可通过既有外部打开入口查看。
- 普通文件本轮提供侧栏与外部打开；独立窗口迁移覆盖网页浏览器和画布。
- 应用目录、添加到我的应用、固定标签和发布（POO-158）不在本轮。
- 所有相关项通过且无阻塞才能确认人工验收通过；失败项记录 ID、步骤、预期、实际、截图及所属窗口/会话。不要把验证码、密码或 token 写入备注。
- HTML 清单可选择通过/失败/阻塞并填写备注，结果自动保存在当前浏览器；测试结束点击「导出结果」保存 JSON，交回本会话。文件版打开时若浏览器禁止本地持久化，使用导出结果保存。
