# Polo client design specification

The repository-maintained Polo desktop-client design specification lives in the [`polo-client-design` skill](../.agents/skills/polo-client-design/SKILL.md).

Use that entrypoint for client implementation, prototypes, settings pages, component changes, and UI review. It routes to the canonical foundations, layout, component, interaction-state, and released-source references without maintaining a second copy here.

The Skill is the design SOT and includes its own runnable HTML and editable prototype source. It is manually refreshed from a pinned stable GitHub Release only when explicitly requested. Its current product version and full source commit are recorded in [`references/source.md`](../.agents/skills/polo-client-design/references/source.md).
