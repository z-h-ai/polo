# 空间切换入口 · 2026-09-21 用户决策

用户要求按讨论结论更新 `mvp-complete-flow-hifi` 原型，并同步必要文档。

已接受的入口方案：顶栏常驻显示当前空间名称与标识，但不在此提供独立下拉切换；头像菜单中提供「切换空间」入口，进入我的空间与有效企业的列表。该操作在同一 Polo 登录账号下变更工作空间，不称为「切换账号」。有运行项时仍进入既有确认、停止、失败/取消恢复流程。圈子不是空间，不列入切换列表。

参考：[飞书项目之企业互联](https://www.feishu.cn/content/1d4ogm3x) 的头像 → 切换工作区路径。此参考只支持入口模式，不代替 Polo 的当前空间可见与安全切换规则。
