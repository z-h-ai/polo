# D-PC-07：视觉与管理入口收口

来源：2026-09-16，本卡会话。

用户原话：

> 1，2，3，4 同意你的推荐。5. M10 管理入口的位置，都放账号菜单。

## 已确认内容

1. **M03 首页：**沿现有首页视觉调整，固定 Polo 助手，最多显示 5 个由用户主动选择的常用 App，并保留稳定“全部 Apps”入口；零常用、真空目录和加载失败分别呈现。
2. **M04 App 关闭：**有活动时展示“取消 / 后台继续 / 终止并关闭”；“后台继续”为普通操作，“终止并关闭”为危险操作；终止失败时保留标签和真实状态。
3. **M07 我的圈子：**放在个人空间稳定导航中，与“全部 Apps”并列；不放进账号设置。列表、详情、审批、浏览器交接、返回、到期和退出沿已确认流程制作页面。
4. **M09 积分提示：**使用 Polo 容器级提示，让不同 App 获得一致反馈；返回后只提供用户主动“查询最新状态”的动作，不自动查询、发送、续写或重试。
5. **M10 管理入口：**企业管理、创作者工作台、平台后台及其他管理端入口全部统一放在账号菜单；空间选择器不再承担管理入口。

## 边界

- 本次确认的是入口位置、交互层级和视觉制作方向；D-PC-01—06 继续有效。
- 不新增 App 内部设计责任，不重做现有助手，不改变浏览器管理端和支付端的职责。
- 当前源码、集成候选和部署验收状态仍分别记录；本次确认不代表实现、发布或验收完成。
- 本轮不授权产品编码。
