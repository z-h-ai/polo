# r12 验证证据

当前证据须以 `artifacts` SHA-256 与最终产物一致为准；时间与文件位置不是通过依据。

- `structure.json`：仓库双表面契约验证。助手场景逐字匹配源码导出；两份嵌入 manifest、来源与设计绑定、场景所有权及故事目标检查。
- `browser.json`：真实 Chromium，通过 `file://` 与临时本地 HTTP 检查所有活动场景的三个视口、助手动作/禁用条件、故事与跨表面消息。`actions[].observation` 明确标出在当前夹具禁用的动作，不冒充已执行。
- `invariants.json`：会话、空间、授权、版本、设备、文件存在、数据源失败、积分/预算与恢复的行为回归。
- `review-continuity.json`：故事只浏览、深链步优先、返回流程、草稿/表单保留、窄窗侧栏/评审面板及消息拒绝。
- `semantic.json`：独立 `/root/semantic_review` 的来源与操作意义复核，包含其实际读取材料的散列、覆盖范围及历史问题的解决情况。
- `reproducibility.json`：连续两次运行当前生成入口，对 MVP/助手产品 HTML、评审 HTML 和两个 manifest 比较字节散列。
- `upstream-validator.json`：通用单表面技能校验器对本轮显式双表面扩展的实际拒绝，**不是通过记录**。
- PNG：各声明视口的当前画面及 800×600 评审壳；用于视觉检查，不表示用户确认。
- `history/`：实施过程中的失败与修复依据，仅适用于各次当时的产物，不作为最终通过记录。

当前验收只覆盖中文浅色离线原型；没有执行真实业务 API、支付、AI 或安装。辅助组件画廊、`reference=1` 与旧截图是历史/辅助参考。正式用户布局确认及客户端业务验收不由本目录自动授予。
