# 首页、圈子与助手范围增量复看

本轮材料：`poo70-workbench-r15-ui-refinement`。授权来源是 2026-10-03 用户逐页反馈，规范落在唯一产品 SoT `docs/client-journey-review/spec.md` §13.11。输入模式为 incremental：当前 r15-classic-style 原型是编辑对象；b82fa1e5 是未受本轮布局调整影响的视觉基线；当前 Renderer 是既有助手的实现依据。原型转译不是当前 Renderer 的整页复刻。

## 实際交付

- 首页「我的应用」；去掉卡片左下角常驻标签及来源数量，保留创作者识别。稳定作品 ID 去重和按圈子来源筛选保留。同一会议应用在增长/设计圈授权的演示事实同步到两圈内容。
- 圈子列表统一头像、标题、创作者、内容摘要、权益/有效期位置及「查看详情」；桌面不再提供分享链接加入或输入入口。原浏览器加入、返回核对和异常场景保留在评审入口。
- 退出仅在订阅区域；移除内容页两个醒目的全局捷径，保留具体技能条目操作。圈子 App 复用首页 `home-app-grid` 和卡片结构。
- 数据工坊有独立内容/订阅/退出确认，年度权益采用相同容器并提供自己的退出确认；确认后只移除对应圈子，数据圈报表失去最后来源后不再出现在首页。年度不虚构作品、创作者或退款结果。新增 4 个场景，未删除原场景/兼容链接。
- 切换一次确认后自动呈现停止→加载→个人空间。取消、Reset、场景浏览和跨表面切换使旧回调失效；停止 ACK 未确认进入失败，保留原企业空间。直接评审进度时定格。动画/退出是会话内模拟，非真实服务操作。
- 助手画布与首页统一；评审壳常驻区分技能管理增量与既有助手行为示意，默认流程聚焦本轮。Spec、设计 Skill、助手 README、源场景注释和派生摘要共同明确：既有聊天/输入/附件/会话导航沿真实代码，不按简化原型重写。

## 生成与检查

MVP `prototype.html` 是既有 HTML 维护源；助手改 `src/mvp/scenes.mjs` 等源后导出；共用样式/行为放 Design System tokens/components。既有 `build_review.py` 更新两表面、统一 manifest、评审壳和派生摘要。历史 SOURCE-EVIDENCE / SCENE-TRACEABILITY / screenshots 不变，用户保留 assets/prototypes 的 373 文件散列不变。

本轮独立复核记录两个发现：旧定时回调在评审进入进度状态后未失效；数据/年度圈缺少自己订阅内退出。修复记录与真实复验保留在 independent/，最终判断由 semantic.json 绑定。作者未改写独立结论。

测试脚本 check_ui_refinement.py 验证实际入口、三视口组件一致、退出/取消/搜索/Reset、自动切换、旧回调失效和缺停止回执；缺 ACK 通过新浏览器页早期协议监听器丢弃 stop 请求注入，非真实后端任务。check_classic_style.py 仍比较未改动的旧版组件，明确排除本轮重设计的圈子行和已授权的助手背景变化。

所有通过声明以本目录 JSON 与顶层 quality-report.json 的最终产物散列为准。上游单表面工具仍拒绝本项目已有 surfaces/aliases 扩展，实际 exit 2 保存在 upstream-validator.json；项目多表面校验独立报告，不能称为上游放行。产品视觉待用户复看，不代表真实 Electron/API/支付/安装已验收。

最终结果：项目完整报告校验 347 项通过；365 场景 × 三视口 × file/HTTP 共 2,190 次显示观察；5,008 次助手操作观察，零页面错误和外部请求。专项 66、导航 69、工作台 75、未变组件风格对照 34、不变量 47、阅读连续性 13 项通过；跨端回归 180 次操作/13 项检查通过。五份生成产物二次构建逐字节一致。独立报告绑定最终四产物，两个发现均已解决。
