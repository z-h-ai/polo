# Polo G2 用户流程、权限与状态

状态：已确认（2026-08-09）

日期：2026-08-09

依据：`CONTEXT.md`、`product-function-baseline.md`、`product-space-contract.md`

本文把 G1 已确认功能转换为可验收的用户场景、权限矩阵和状态规则。Part 1 使用业务语言供产品确认；Part 2 记录由这些场景推导出的技术约束。页面结构、控件布局和视觉由 G3 处理。

# Part 1：用户场景清单

## 领域 A：账号与空间

### S-001：无邀请用户第一次进入 Polo

- **角色**：新注册普通用户
- **触发**：用户完成注册并首次登录 Polo 客户端
- **期望**：直接进入“我的空间”，可以看到 Polo 内置 App 和 Polo 助手；不要求先创建或加入组织
- **异常**：
  - 我的空间仍在创建 → 显示正在准备并自动重试，不能创建第二个我的空间
  - 账号被暂停 → 不进入任何空间，显示账号受限及恢复渠道
- **优先级**：P0

### S-002：接受企业邀请

- **角色**：普通用户
- **触发**：用户在浏览器打开有效的指定成员邀请或快速共享邀请
- **期望**：在轻量落地页完成注册/登录；指定邀请身份匹配后直接加入，快速共享邀请审批后加入；成为企业 Member 后下载或打开 Polo 桌面客户端，企业空间出现在空间列表中，但不强制改变其他设备的当前空间
- **异常**：
  - 邀请已过期、取消或使用完 → 明确说明邀请不可用，不创建成员关系
  - 快速共享邀请仍待审批 → 可以下载并登录客户端，但批准前不显示企业空间
  - 指定邀请登录账号不匹配 → 要求切换到受邀账号
  - 用户已经是有效成员 → 返回现有成员关系，不重复加入
  - 用户已被该企业暂停 → 邀请不能绕过暂停
- **优先级**：P0

### S-003：创建企业

- **角色**：完成基础验证的普通用户
- **触发**：用户选择创建企业并提交必要资料
- **期望**：创建一个企业及对应企业空间；创建者成为唯一 Owner，并进入企业组织管理端完成后续配置
- **异常**：
  - 重复提交 → 不创建重复企业
  - 创建失败 → 用户留在原空间，已输入资料可安全重试
- **优先级**：P0

### S-004：没有运行任务时切换空间

- **角色**：拥有多个空间的普通用户
- **触发**：用户从我的空间切换到企业 A，或从企业 A 切回我的空间
- **期望**：应用、Skills、Polo 助手、文件、权限和费用承担方一起刷新；另一台设备不跟随切换
- **异常**：
  - 目标企业访问权已失效 → 不进入目标空间，并从可用空间中移除或标记不可用
  - 刷新失败 → 不显示新旧空间混合内容，允许重试或返回原空间
- **优先级**：P0

### S-005：存在运行任务时切换空间

- **角色**：正在运行 App、Polo 助手或 AI 任务的用户
- **触发**：用户尝试切换空间
- **期望**：Polo 告知必须先终止当前空间的运行项；全部终止成功后才切换
- **异常**：
  - 用户取消终止 → 留在原空间，任务继续
  - 任一任务终止失败 → 不切换空间，显示失败项并允许重试
- **优先级**：P0

### S-006：当前企业访问权被撤销

- **角色**：当前正在企业空间中的 Member/Manager
- **触发**：成员被暂停、移除，或企业进入不可使用状态
- **期望**：停止新的 App/AI 操作；终止该企业的运行项；安全返回我的空间；企业数据不复制到个人空间
- **异常**：
  - 我的空间暂时无法加载 → 显示安全受限页，不继续展示企业内容
- **优先级**：P0

### S-007：查看和管理个人账号

- **角色**：普通业务账号
- **触发**：用户查看个人费用、账号状态或安全设置，或选择退出登录
- **期望**：只看到个人账号与我的空间范围的信息；企业账单和创作者收入进入各自管理端；退出登录不删除本地业务数据
- **异常**：账号存在 Owner、Creator Owner 或未结财务责任时申请注销 → 列出必须先处理的事项，不能直接注销
- **优先级**：P1

## 领域 B：个人圈子、作品与 Polo 助手

### S-010：加入免费或仅邀请圈子

- **角色**：普通用户
- **触发**：用户通过定向邀请、通用加入链接或二维码进入圈子并确认
- **期望**：免费链接直接加入，付费链接进入支付；仅邀请圈子的定向邀请在目标身份匹配后直接加入，通用链接/二维码只提交待 Creator Owner 审批的申请；加入成功后进入圈子详情并展示已获得作品，但不自动打开 App 或启用 Skill
- **异常**：
  - 链接失效或圈子停止加入 → 不建立成员资格
  - 定向邀请身份不匹配或仅邀请申请未批准 → 不建立成员资格
  - 用户已加入 → 打开现有圈子关系，不重复创建
- **优先级**：P0

### S-011：加入付费圈子

- **角色**：普通用户
- **触发**：用户查看价格和续费规则后确认购买
- **期望**：支付成功后成员资格生效，圈子作品进入我的空间；内容费用与 AI 算力费用分开显示
- **异常**：
  - 支付失败或结果未知 → 不重复扣款，显示可核对状态并允许恢复
  - 圈子价格在确认前变化 → 要求用户按新价格重新确认
- **优先级**：P0

### S-012：使用圈子 App

- **角色**：有效圈子成员
- **触发**：用户主动打开一个已分发 App
- **期望**：使用启动时的稳定版本；数据、文件、结果和算力费用归我的空间
- **异常**：
  - 授权已撤销或版本被平台阻断 → 不启动，并说明是授权或安全原因
  - 新版本在执行过程中发布 → 当前执行保持启动版本，下次启动再使用新稳定版本
- **优先级**：P0

### S-013：启用 Skill 并使用 Polo 助手

- **角色**：我的空间用户
- **触发**：用户明确启用一个已授权 Skill，并在 Polo 助手中提出相关任务
- **期望**：Polo 助手只调用我的空间已启用 Skills；启用状态按账号和 ProductSpace 保存并跨该账号设备同步；对话、附件和费用保存在我的空间
- **异常**：
  - 同名能力来源不明确 → 先让用户选择来源，不静默调用
  - Skill 在执行前失效 → 不调用并提示重新选择可用能力
- **优先级**：P0

### S-014：隐藏或恢复单个圈子作品

- **角色**：圈子成员
- **触发**：用户不想使用某项作品，但仍希望保留圈子成员资格
- **期望**：作品从个人常用入口隐藏、停用或移除；用户之后可以从圈子作品列表恢复
- **异常**：
  - 作品授权本身已失效 → 不能通过恢复操作重新获得授权
- **优先级**：P1

### S-015：取消续费、立即退出和续费失败

- **角色**：付费圈子成员
- **触发**：用户取消续费、选择立即退出，或自动续费失败
- **期望**：
  - 取消续费 → 当前已付周期内继续使用，到期后停止
  - 立即退出 → 确认后立即撤权，并提示剩余周期不再使用
  - 续费失败 → 进入宽限期，期间可用并提示补款；宽限期结束后失效
- **异常**：退款、拒付或权益状态不一致 → 显示处理中并交由平台订单异常处理，不能重复扣款或重复授权
- **优先级**：P0

### S-016：圈子或作品停止提供

- **角色**：圈子成员
- **触发**：创作者停止分发、关闭圈子，或平台阻断作品
- **期望**：不能再启动或调用失效作品；Polo 保留最小记录以及已导出/保存到我的空间的结果
- **异常**：Web App 内部历史是否可见 → 按该 App 的数据保留声明处理，历史不能绕过授权继续执行
- **优先级**：P0

## 领域 C：企业成员使用

### S-020：企业 Member 使用企业 App

- **角色**：企业 Member
- **触发**：Owner/Manager 已向该成员或其成员组分发企业 App
- **期望**：成员在企业空间打开 App；数据、文件、结果和费用全部归企业
- **异常**：
  - 成员无可见权限 → App 不出现在目录，也不能通过旧链接启动
  - 企业停用 App → 不能继续启动，但不自动删除业务数据
- **优先级**：P0

### S-021：企业 Member 使用 Skills 与 Polo 助手

- **角色**：企业成员
- **触发**：成员启用企业分发 Skill，或使用企业空间 Polo 助手
- **期望**：只使用企业授权 Skills，由企业承担算力；不读取个人圈子 Skills、个人对话或个人文件
- **异常**：切回我的空间 → 看到独立助手实例，不出现企业历史
- **优先级**：P0

### S-022：成员离开企业

- **角色**：被暂停或移除的企业成员
- **触发**：Owner 更改成员状态，或成员关系依法失效
- **期望**：用户立即失去企业空间访问权；其在企业产生的数据继续归企业，由企业决定接管人
- **异常**：用户设备仍有缓存 → 只能显示不可用说明，不能离线继续启动企业能力
- **优先级**：P0

### S-023：企业欠费、治理暂停或关闭中

- **角色**：企业 Owner/Manager/Member
- **触发**：企业欠费、被平台暂停或进入 `closing` 关闭处理状态
- **期望**：停止新的 App/AI 执行和作品变更；Owner 仍可处理账单、导出和申诉；Manager/Member 不能绕过限制
- **异常**：限制解除 → 只恢复原本仍有效的成员、目录和启用状态
- **优先级**：P0

## 领域 D：企业组织管理

### S-029：查看企业概览和维护企业资料

- **角色**：Enterprise Owner/Manager
- **触发**：管理员进入企业组织管理端处理日常事项
- **期望**：看到企业状态、成员、目录、用量和待处理异常；Owner 可以修改关键企业资料，Manager 只能处理被授权的日常管理事项
- **异常**：企业受限 → 优先展示限制原因和 Owner 可执行的恢复路径，不允许 Manager 绕过限制
- **优先级**：P0

### S-030：邀请和查看成员

- **角色**：Enterprise Owner/Manager
- **触发**：管理员需要让新成员加入企业
- **期望**：可以创建指定邮箱/手机号邀请，也可以创建带有效期、人数上限和审批的快速共享链接/二维码；查看邀请、申请和成员状态；加入者默认成为 Member；加入完成后引导下载或打开 Polo 桌面客户端
- **异常**：邀请撤销、过期、目标不匹配、人数用完或申请未获批准 → 不加入企业，并保留可审计结果
- **优先级**：P0

### S-031：调整成员角色和状态

- **角色**：Enterprise Owner
- **触发**：需要晋升 Manager、降级、暂停、恢复或移除成员
- **期望**：变更立即影响管理入口和企业访问，并记录原因与操作者
- **异常**：Manager 尝试执行 → 拒绝；目标是唯一 Owner → 必须改走所有权转让
- **优先级**：P0

### S-032：转让企业所有权

- **角色**：Enterprise Owner
- **触发**：Owner 把所有权交给一名有效 Manager
- **期望**：一次操作完成新 Owner 与原 Owner 身份交换；企业始终只有一个有效 Owner
- **异常**：目标不是有效 Manager，或并发状态已变化 → 整体失败，不留下双 Owner 或无 Owner
- **优先级**：P0

### S-033：成员组和作品可见范围

- **角色**：Enterprise Owner/Manager
- **触发**：管理员把客服、销售等成员归入简单成员组，并按组分发作品
- **期望**：成员组不可嵌套；成员变更后，其作品可见范围按最新有效关系重新计算；当前成员组不承担预算配额
- **异常**：引用其他企业或平台全局组 → 拒绝，不产生跨企业授权
- **优先级**：P0

### S-034：导入并检查 App/Skill

- **角色**：Enterprise Owner/Manager
- **触发**：企业收到创作者、FED 或内部服务商交付包
- **期望**：上传后显示来源、版本、检查结果；通过检查后形成企业独立、锁定实例
- **异常**：检查失败 → 不进入成员目录；允许修复后提交新版本，不能覆盖原检查记录
- **优先级**：P0

### S-035：向企业成员分发作品

- **角色**：Enterprise Owner/Manager
- **触发**：企业实例通过检查，管理员配置全员、角色或成员组可见范围并启用
- **期望**：符合范围的成员目录更新；不符合范围的成员无法通过旧链接访问
- **异常**：配置引用失效成员组 → 不发布不完整策略，并提示修正
- **优先级**：P0

### S-036：上传新交付包、采用或回退企业版本

- **角色**：Enterprise Owner/Manager
- **触发**：企业收到新的 App/Skill 交付包并重新上传，或当前企业版本需要回退
- **期望**：Polo 不发现或提醒创作者版本变化；新包形成企业候选版本，检查通过并由企业明确选择后才切换；已开始执行保持启动版本；保留上传人、采用人与企业版本历史
- **异常**：新交付包未通过检查或已被治理阻断 → 不能采用
- **优先级**：P0

### S-037：停用或移出企业作品

- **角色**：停用由 Owner/Manager；移出目录由 Owner
- **触发**：企业停止继续使用某个 App/Skill
- **期望**：停用停止新使用，移出目录删除企业目录关系，但两者都不等于 App 业务数据已删除；当前不提供通用一键删除，数据请求按 App 声明或平台人工支持处理
- **异常**：实际存储尚未确认删除，或存在法务、账单、审计保留要求 → 不能显示数据已经删除，并说明处理状态
- **优先级**：P1

### S-038：授权创作者协助排障

- **角色**：Enterprise Owner
- **触发**：企业需要创作者查看某次问题的有限材料
- **期望**：企业明确选择材料范围、用途和失效时间；所有访问显示真实操作者并可撤销
- **异常**：授权过期、撤销或访问超出范围 → 立即拒绝并记录尝试
- **优先级**：P1

### S-039：关闭企业

- **角色**：Enterprise Owner
- **触发**：Owner 发起关闭企业
- **期望**：进入 `closing`，停止邀请、导入、分发变更和新执行；Owner 保留账单、导出、申诉和撤销能力；平台完成责任检查后人工确认关闭，当前不设置自动关闭日期
- **异常**：存在未完成账单、退款、所有权、数据或法务保留 → 阻止最终关闭并列出待处理项
- **优先级**：P1

## 领域 E：创作者生产与经营

### S-040：获得创作者资格并首次进入工作台

- **角色**：被平台授予资格的普通业务账号
- **触发**：平台完成线下审核并授予创作者资格
- **期望**：账号获得创作者工作台入口；系统不自动创建圈子
- **异常**：资格暂停或撤销 → 入口保留并进入只读状态，可查看历史、财务、原因、申诉和导出，但禁止新增、更新和发布
- **优先级**：P0

### S-041：创建圈子并设置加入模式

- **角色**：有效创作者
- **触发**：创作者创建圈子并选择免费、仅邀请或付费订阅
- **期望**：创作者成为该圈子的 Creator Owner；免费链接可直接加入，付费链接进入支付；仅邀请圈子的定向邀请匹配后直接加入，通用链接/二维码只创建待审批申请；空圈可自由切换模式，免费/仅邀请切换只影响后续加入
- **异常**：资格在提交前失效 → 不创建圈子；存在付费成员或订单时尝试直接切为免费/仅邀请 → 拒绝并要求关闭或新建圈子
- **优先级**：P0

### S-042：创建并发布 App/Skill

- **角色**：有效创作者
- **触发**：创作者登记 Web App/Skill 作品，上传在工作台外完成的制品并提交检查
- **期望**：工作台只管理作品身份、制品、检查、版本、发布和分发，不提供在线代码、低代码或 Prompt/Skill 编辑；低风险更新通过自动检查后可发布，首次、高风险或异常版本需要平台人工批准
- **异常**：检查失败或审批拒绝 → 保留问题和历史，修复后创建新提交；不能绕过检查发布
- **优先级**：P0

### S-043：把同一作品分发到多个圈子

- **角色**：同时拥有多个圈子的 Creator Owner
- **触发**：创作者选择已发布作品并选择一个或多个自有圈子
- **期望**：各圈子建立指向作品的独立分发关系，不固定或复制版本；所有圈子新启动统一使用当前稳定版本，回退通过重新指定历史已检查版本完成
- **异常**：创作者不再拥有目标圈子 → 不能新增或修改该圈子的分发
- **优先级**：P0

### S-044：管理付费成员与价格

- **角色**：Creator Owner
- **触发**：查看成员、赠送资格、处理违规、调整下一周期价格
- **期望**：风险暂停记录原因并处理未使用周期；普通经营原因只能到期不续费；涨价不影响当前周期并要求成员确认
- **异常**：创作者尝试立即吞掉剩余权益或读取成员余额/业务内容 → 拒绝
- **优先级**：P0

### S-045：创作者资格被暂停或撤销

- **角色**：创作者、圈子成员、平台管理员
- **触发**：平台因资格或治理原因暂停/撤销创作者资格
- **期望**：立即停止新增和修改；保留圈子、作品、订单、结算、原因、申诉和导出的只读访问；无安全风险的稳定作品按平台给出的过渡安排继续或停止
- **异常**：涉及严重安全风险 → 不适用普通过渡，相关版本立即全局阻断；需要交接时只能把该账号全部圈子和作品整体转给一个有效创作者，否则全部关闭
- **优先级**：P0

### S-046：关闭付费圈子

- **角色**：Creator Owner
- **触发**：创作者停止经营圈子
- **期望**：Creator Owner 只能发起 `closing`；立即停止新加入和自动续费，默认服务到已付周期结束；提前关闭由平台处理未使用周期退款，平台核清权益和资金责任后确认 `closed`
- **异常**：仍有退款、拒付或待结算责任 → 平台不能确认最终关闭；Creator Owner 不能绕过平台直接硬关闭
- **优先级**：P0

### S-047：查看经营数据和用户反馈

- **角色**：Creator Owner
- **触发**：创作者查看圈子和作品表现，或处理用户主动反馈
- **期望**：只查看成员状态数量、作品/版本启动和完成失败聚合、技术失败类型、用户主动评分，以及分圈收入和结算；单次反馈只包含用户描述、主动附带的材料/技术日志，创作者可更新状态并回复一次结果；一个创作者账号只维护一套收款资料
- **异常**：尝试查看个人余额、单用户算力金额、其他圈子关系、对话、文件、App 输入输出或平台推断的业务质量分 → 拒绝；实时聊天、远程控制和完整客服工单不在当前范围
- **优先级**：P0

## 领域 F：平台运营与治理

### S-050：授予、暂停或撤销创作者资格

- **角色**：平台管理员
- **触发**：完成线下审核、发现资格问题或结束创作者关系
- **期望**：记录操作者、目标、原因和时间；暂停立即停止圈子新加入和自动续费，已付成员按截止时间继续使用且不补扣错过续费；资格变化不自动创建或删除圈子，原创作者保留必要只读访问
- **异常**：撤销会留下无人负责的圈子或共享作品 → 当前只能把目标账号的全部圈子和作品整体转给一个有效创作者，或全部关闭，不能拆分转让
- **优先级**：P0

### S-051：审批作品版本

- **角色**：平台管理员
- **触发**：首次、高风险或异常版本进入人工队列
- **期望**：可以查看创作者明确提交的版本包、包内代码与资源、manifest、权限声明、检查报告和审批说明，批准或拒绝并记录原因；不能读取未提交的开发资料或用户业务内容
- **异常**：必要检查未完成 → 不能批准
- **优先级**：P0

### S-052：全局阻断严重风险版本

- **角色**：平台管理员
- **触发**：确认某版本存在严重安全风险
- **期望**：重新验证身份并填写原因后，立即阻止该版本在所有个人和企业空间启动并终止活动执行；保留已保存历史结果并标记来源版本已阻断；通知受影响方
- **异常**：已有执行无法安全停止 → 标记并持续处置，不能把前台隐藏当作已经停止
- **优先级**：P0

### S-053：处理普通违规与恢复治理

- **角色**：平台管理员
- **触发**：发现非紧急违规，或误判/整改完成
- **期望**：普通违规暂停新增分发并给出整改期；受影响责任主体可提交一条处理中轻量申诉，平台给出维持、修改或撤销的一次结论；恢复时只移除平台阻断，不覆盖用户、企业或成员的独立停用状态
- **异常**：版本仍不符合当前规则 → 不能恢复
- **优先级**：P0

### S-054：处理订单、退款、拒付和结算异常

- **角色**：平台管理员
- **触发**：圈子订阅或个人/企业付款出现异常
- **期望**：按真实付款和权益状态处理；退款、拒付、权益修正、结算和补偿额度使用幂等追加记录，临时配额必须带失效时间；不能修改余额、历史用量、原始订单或永久套餐，并经过重新验证、原因和不可修改审计
- **异常**：支付结果未知或并发处理 → 保持处理中并防止重复退款、重复结算或重复授权
- **优先级**：P0

### S-055：恢复失效企业 Owner

- **角色**：平台管理员
- **触发**：企业唯一 Owner 失效，现有有效 Manager 提交恢复申请
- **期望**：验证企业主体与申请人后恢复所有权；不读取企业业务内容
- **异常**：没有可验证主体、有效 Manager 或存在争议 → 不恢复，进入人工异常处理
- **优先级**：P1

### S-056：限时支持或紧急内容访问

- **角色**：平台管理员
- **触发**：数据所有方授权排障，或发生重大安全事件
- **期望**：当前不做双人审批；限定具体账号、空间、App、文件或材料，单次最长四小时；始终显示真实操作者，通知数据所有方，每次查看和下载独立审计并可提前撤销
- **异常**：缺少重新验证、原因、授权或安全依据，或申请整租户/超过四小时访问 → 不允许访问
- **优先级**：P1

### S-057：管理平台工作人员

- **角色**：现有平台管理员
- **触发**：授予或撤销平台管理员
- **期望**：变更可审计；平台始终至少有一个有效管理员
- **异常**：尝试撤销最后一个有效管理员 → 拒绝
- **优先级**：P0

## 领域 G：网络、并发与版本兼容

### S-060：网络不可用

- **角色**：Polo 客户端用户
- **触发**：用户离线打开客户端，或运行中断网
- **期望**：可以查看明确允许的本地内容，不显示缓存为最新授权；是否允许启动或继续运行按本文待确认项决定
- **异常**：无法验证授权或提交费用记录 → 不把未知状态显示为成功
- **优先级**：P0

### S-061：多人同时修改同一企业或作品

- **角色**：企业管理员、创作者、平台管理员
- **触发**：两人或两个页面基于旧状态提交互相冲突的修改
- **期望**：先成功的有效修改保留；后提交者看到内容已经变化，需要刷新后重新确认
- **异常**：所有权转让、版本发布、退款和治理等操作不得部分成功
- **优先级**：P0

### S-062：客户端契约不一致

- **角色**：使用与服务端 ProductSpace 契约不一致客户端的普通用户
- **触发**：客户端无法安全解析服务端 `contractVersion`
- **期望**：明确提示升级，不把 Creator Circle、旧 Organization 或缓存错误解释为当前空间；未公开发布阶段不维持旧客户端兼容运行
- **异常**：用户暂时无法升级 → 允许查看升级帮助，但不能继续执行可能串空间的操作
- **优先级**：P0

## 2. 状态模型

### 2.1 业务账号

```text
有效 ──平台暂停──> 暂停 ──平台恢复──> 有效
有效 ──用户申请注销──> 注销冷静期 ──撤销申请──> 有效
注销冷静期 ──责任与保留检查通过──> 已注销
```

- 暂停立即撤销登录，不删除数据、成员关系、Owner 记录和财务责任。
- 暂停终止该账号发起的活动执行，但不影响同一企业其他成员的执行；恢复后不自动重启旧任务。
- Owner/Creator Owner 未完成转让、关闭或财务处理时，不能完成注销。
- 已注销后的业务内容按保留策略删除或匿名化；法定最小记录继续隔离保留。

### 2.2 Enterprise 与限制轴

```text
active ──Owner 发起关闭──> closing ──Owner 撤销关闭──> active
closing ──平台责任检查通过并确认──> closed
active/closing ──平台治理──> suspended ──治理解除──> 原生命周期状态
```

账单欠费是独立限制轴，不复用 `suspended`：

- 治理暂停与欠费都停止新执行和作品变更。
- 治理暂停与欠费都终止该企业空间中的活动执行；解除限制不自动重启旧任务。
- Owner 保留账单、导出和申诉能力。
- 恢复只解除对应限制，不自动恢复其他停用、成员或作品状态。

### 2.3 EnterpriseMembership

```text
active <──Owner 恢复── suspended
active/suspended ──Owner 移除──> removed
removed ──新邀请及规则允许──> active Member
```

- 只有 Owner 可以改变成员角色或状态、移除成员。
- 唯一 Owner 不走通用成员状态变更；必须先原子转让所有权。

### 2.4 CreatorQualification

```text
未授予 ──平台授予──> active
active ──平台暂停──> suspended ──平台恢复──> active
active/suspended ──平台撤销──> revoked
```

- `suspended/revoked` 立即停止创建圈子、创建/更新作品和发布。
- `suspended/revoked` 同时停止圈子新加入和自动续费；已付成员按过渡截止时间继续使用，暂停期间错过的续费不补扣。
- 资格状态不删除 CreatorCircle、Artifact、成员、收入或历史；原账号保留订单、结算、原因、申诉和导出的只读访问。
- 当前版本的资产交接以创作者账号为整体边界，全部圈子和作品只能原子转给一个有效创作者，或全部关闭。
- 无安全风险稳定作品的过渡由 S-045 的确认规则决定；安全阻断独立且优先。

### 2.5 CircleMembership

```text
active ──取消续费──> cancelled ──已付周期结束──> expired
active ──续费失败──> grace_period ──补款成功──> active
grace_period ──宽限期结束──> expired
active/grace_period/cancelled ──风险暂停──> suspended
active/grace_period/cancelled ──立即退出──> expired
```

- `cancelled` 表示停止续费但当前周期仍可用。
- `suspended/expired` 不允许新启动或调用圈子作品。
- 免费、邀请、付费和赠送是加入方式，不产生另一套状态机。

### 2.6 CreatorCircle

```text
active ──Creator Owner 发起关闭──> closing
closing ──平台权益与资金检查通过──> closed
```

- `closing` 立即停止新加入和自动续费，默认保留现有成员到已付周期结束。
- 提前结束权益由平台处理退款；存在退款、拒付或待结算责任时不能转为 `closed`。
- 当前版本不允许 Creator Owner 绕过平台直接完成硬关闭。

### 2.7 作品与 ArtifactVersion 的正交状态轴

为避免一个状态字段同时表达作品、版本、检查和治理，产品行为按四个轴解释：

| 状态轴 | 典型状态 | 决定什么 |
| --- | --- | --- |
| 作品生命周期 | 活跃、已归档 | 作品是否允许所有圈子新启动和继续发布 |
| 版本生命周期 | 草稿、已发布、当前稳定、已撤回 | 哪个已检查版本供所有圈子成员下一次启动使用 |
| 平台检查 | 待检查、检查失败、待人工审批、已通过 | 版本是否满足发布或企业导入前置条件 |
| 平台治理 | 正常、暂停新增分发、全局阻断 | 已有授权是否还能新增或继续启动 |

圈子分发指向作品，不允许按圈子固定不同版本。最终可运行必须同时满足：作品活跃、当前稳定版本已发布且检查通过、没有全局阻断，并且当前空间的授权和本地激活仍有效。普通撤回、归档或停止分发只阻止新启动，已开始执行保持启动版本；严重安全风险的全局阻断可以终止运行。

全局阻断不自动删除已经保存的历史结果、文件或最小使用记录；历史记录必须标记来源版本已被阻断，具体危险文件通过独立隔离动作处理。

### 2.8 EnterpriseArtifactInstance

```text
待检查 ──检查通过──> 可配置 ──Owner/Manager 启用──> enabled
enabled <──Owner/Manager 启用/停用──> disabled
enabled/disabled ──Owner 明确删除──> deleted
```

- 实例固定当前企业采用版本，不跟随圈子或创作者自动更新。
- 全局治理是独立覆盖层；解除治理后仍遵守企业原本的 enabled/disabled 状态。
- deleted 不能通过普通启用恢复；业务数据处理遵守独立保留流程。

### 2.9 App/AI 执行

```text
准备 ──启动成功──> running ──完成──> completed
running ──用户/系统终止──> stopping ──终止完成──> terminated
准备/running/stopping ──异常──> failed
```

- 执行创建时固定账号、空间、Workspace、作品实例和版本。
- 存在 `running/stopping` 时不能切换空间。
- 终止失败时保持原空间，不把任务隐藏或标记成已停止。

# Part 4：已确认的产品事项

## G2-Q1：离线时允许做什么

确认结论：离线时可以查看已保存在本机的历史结果、文件和目录说明，但不能启动新的 App、Polo 助手或 AI 执行；网络在执行中断开时，停止新的 AI/网络调用，并让当前任务进入“等待恢复或终止”，不把它当作成功完成。

影响：如果允许离线启动，客户端无法及时验证成员撤权、作品全局阻断和付款主体，需要新增离线授权租约、风险期限和延迟计量规则。

## G2-Q2：非安全原因暂停创作者资格时，稳定作品如何过渡

确认结论：平台暂停资格时必须选择一个明确的过渡截止时间并通知创作者和成员；截止前稳定作品可以继续运行但不能发布新版本或新增分发，截止后停止。严重安全风险不使用过渡期，立即全局阻断。

影响：如果暂停资格就立即停止所有稳定作品，会直接中断无风险用户任务；如果没有截止时间，平台会长期保留无人负责的作品。

## G2-Q3：企业授权创作者排障的最长时间

确认结论：一次授权最长 24 小时，Enterprise Owner 可以提前撤销；授权必须限定具体 App、问题和材料，不能开放整个企业空间。若仍未解决，由 Owner 重新授权。

影响：没有最长时间会形成创作者的长期隐式访问；时间过短则复杂排障需要频繁重新授权。

以上三项全部确认，本文场景、权限和状态直接进入 G3，G2 已通过。
