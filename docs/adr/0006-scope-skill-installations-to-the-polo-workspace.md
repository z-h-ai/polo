# Scope Skill Installations to the Polo Workspace

A Skill Installation belongs to the Polo Workspace that materializes it, not to the account that initiated the install. Any user with access to that workspace may continue using the local Skill even without access to its publishing Creator Space, while catalog browsing, downloading, and updating still require current membership; remote workspaces therefore install through the `server-core` that owns their filesystem.
