# D-PC-09 · 同一作品跨多个圈子分发与客户端授权聚合

日期：2026-09-16（2026-09-17 在 POO-70 同步）

## 用户确认

用户消息 `msg_01a0a9a3-bbdd-7333-a786-06be70da033d` 明确回复：

> 好，按你的推荐处理，修改文档

该回复接受了推荐消息 `msg_0023750a6d4c79b6016aaa66819a6887d08efbc9395fdfa936` 的完整范围：

- 同一创作者的同一个 App/Skill 可以分发到自己的多个圈子。
- 作品归属、版本和发布生命周期保持唯一。
- 每个圈子的分发关系、成员、定价、收入和关闭责任独立。
- 个人“我的空间”按作品去重，同时保留全部有效授权来源。
- 停止某圈分发、退出圈子或该圈授权失效，只撤销该来源；其他有效来源继续支持访问。
- 最后一个有效来源失效时，作品才进入不可用与恢复路径。
- 发布新稳定版时提示所有受影响圈子；各圈成员后续启动使用同一个新稳定版。
- 需要独立品牌、功能、版本或发布时间时，创作者另建作品。

## 替代关系

该确认替代 POL-94 第二轮材料中的旧“一个作品只能分发到一个圈子”限制。旧材料继续保留为历史来源，不再作为当前产品规则；不得按文档日期、旧代码或旧原型反推用户撤销了本决定。

## 客户端直接影响

- 同一作品从两个圈子取得授权时，“全部 Apps”只显示一个作品条目，并展示多个有效来源。
- 某个来源撤销或到期后，来源列表更新；只要仍有一个有效来源，作品继续可用。
- 最后一个有效来源失效后，作品才显示不可用原因和对应恢复入口。
- 企业空间只消费企业自己导入、启用和分发的企业实例，不显示个人圈子来源，也不能借个人圈子权益补授权。

以上是已确认产品行为。本轮修改后的原型仍须视觉复看；规则确认不等于布局或视觉验收。
