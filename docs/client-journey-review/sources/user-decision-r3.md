# POO-70 产品确认 r3
确认人：需求提出者铭龙。来源：本卡会话。

用户原话：
APP产出的内容，它结果的保存其实属于APP它自己去负责的。我们Polo作为一个品，就是这个APP的容器。你刚说的找回，首先APP的列表，它如果用户能打开的话，一定是在我们Polo的这个应用列表里面可以有这个APP的，所以才能才能打开。举个例子，Polo就有点像浏览器，然后这些APP可能就是某些网页或者Web来提供的这服务。我们作为浏览器肯定不需要管这些东西，但是我们未来的话应该是需要提供SDK或者类似的API，然后让这些APP的创作者来去调用Polo的能力的。但这些是后面的事情，跟我觉得跟现在的责任没有太大关系。

接受范围 D-PC-02：App 自行负责产出内容、保存和内部历史/找回；Polo 作为容器负责当前授权应用列表及打开入口。本轮不承担第三方 App 结果存储、统一索引或保存状态判断。面向创作者的 SDK/API 能力开放留后续，非本轮前置。未确认具体 SDK 形式、删除现有底层接口或改变计费授权规则；未撤销 Polo 助手自有会话/附件职责。整份 Spec 未接受，不授权修改产品代码或重置运行任务。
