# POO-70 r9 · 主说明与共享边界整理依据

日期：2026-09-17

## 用户本轮直接明确的产品边界

- 圈子向个人用户提供 App/Skill 授权；多个圈子的有效权益聚合在唯一“我的空间”。
- 圈子不是 ProductSpace，也不是空间切换项。
- 企业只使用自己导入、启用并分发的 App/Skill，不继承成员个人圈子权限，也不订阅圈子。
- 当前不建设公开 App/圈子市场。
- 私域分发可以通过分享链接、二维码、定向邀请、付费入口或按规则审批等方式承接，不等于所有圈子一律只能邀请加入。
- 已确认产品规则与首发范围分别记录；实施延期不表示撤销规则。

## 本轮文档与原型维护授权

- 在 POO-70 既有成果上选定一份《Polo 客户端产品与用户流程说明》作为本端唯一主说明，不另造竞争版本。
- 完整核对 POL-68、POL-94、POL-112 和本卡确认记录；已有确认直接继承，未接受建议仍标待决。
- 既有 POO-71 高保真任务继续复用，不新建同类卡、不重复启动 AI run。
- 原型违反已有明确规则时直接修正；新功能、权限、费用、数据或跨端变化仍须另行确认。
- 本轮不启动正式产品编码或发布。

## 接受边界

以上是本轮用户明确给出的约束，可直接写入 D-PC-08 和维护契约。它不代表用户已复看本轮修改后的高保真视觉，也不证明真实产品已经实现或验收。
