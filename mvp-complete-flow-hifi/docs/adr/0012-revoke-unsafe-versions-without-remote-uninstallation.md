# Revoke unsafe versions without remote uninstallation

Owner, Manager, or platform Admin may revoke one unsafe Published Version without archiving the entire Artifact, blocking new downloads and moving the latest-version pointer to the highest remaining safe version. Existing Skill Installations are never remotely deleted or disabled; Polo warns affected workspaces and offers an explicit update or uninstall because the workspace remains authoritative over its local content.
