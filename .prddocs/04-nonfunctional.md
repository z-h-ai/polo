# 04 - 非功能需求

## NFR-1：性能

### NFR-1.1 响应延迟
- 用户发送消息后，流式首 Token 应在 2 秒内出现
- 工具执行结果应实时流式返回
- 大文件附件转换不应阻塞 UI

### NFR-1.2 资源使用
- Electron 应用在典型使用场景下内存占用应保持在 500MB 以下
- 无头服务器在 4GB VPS 上应支持 10 个以上并发会话
- 会话持久化使用高效的 JSONL 格式（仅追加）

### NFR-1.3 大响应处理
- 超过约 60KB 的工具响应会自动使用 Claude Haiku 进行摘要
- 基于意图感知的摘要保留关键上下文
- 在 MCP 工具模式中注入 `_intent` 字段以实现聚焦式摘要

### NFR-1.4 构建性能
- 渲染进程使用 Vite 构建（开发时快速 HMR）
- Electron 主进程使用 esbuild 打包
- Docker 构建使用层缓存加速依赖安装

## NFR-2：可靠性

### NFR-2.1 会话持久化
- 所有对话历史以 JSONL 格式保存到磁盘
- 崩溃恢复：会话可在应用崩溃后保留
- 远程服务器会话在客户端断开连接后仍然持久化

### NFR-2.2 错误处理
- Sentry 集成，用于崩溃报告
- LLM 提供商不可用时的优雅降级
- 代理子进程隔离（崩溃不影响主进程）
- Pi 代理子进程中的未捕获异常处理

### NFR-2.3 并发操作
- 工具执行预取，支持并行工具调用
- 压缩序列化以防止数据竞争
- 基于微任务的事件排序，确保正确的对话轮次锚定

## NFR-3：安全

### NFR-3.1 凭据存储
- 所有存储的凭据使用 AES-256-GCM 加密
- 加密密钥从机器特定数据派生
- 凭据文件：`~/.polo-ai/credentials.enc`

### NFR-3.2 网络安全
- WebSocket 连接支持 TLS（wss://）
- 服务器访问使用 Bearer Token 认证
- MCP 子进程的环境变量清理
- 阻止的环境变量：ANTHROPIC_API_KEY、AWS_*、GITHUB_TOKEN、OPENAI_API_KEY 等

### NFR-3.3 权限系统
- 三级权限模型：safe（只读）、ask（提示确认）、allow-all（自动批准）
- 在工具执行层进行权限强制
- PreToolUse 钩子用于权限检查

### NFR-3.4 OAuth 安全
- OAuth 使用 PKCE 流程（Microsoft、Google）
- Token 刷新与安全存储
- 每个来源的凭据隔离

## NFR-4：可用性

### NFR-4.1 跨平台
- macOS（arm64、x64）
- Windows（x64）
- Linux（x64、arm64）
- Docker（多架构）

### NFR-4.2 辅助功能
- 所有主要操作均支持键盘快捷键
- Cmd+N（新建聊天）、Cmd+1/2/3（面板焦点）、Cmd+/（快捷键对话框）
- SHIFT+TAB 切换模式

### NFR-4.3 本地化
- 带验证翻译的 i18n 框架
- 语言自动检测
- 支持英语、西班牙语、简体中文
- 使用区域特定库（date-fns）进行日期格式化

### NFR-4.4 主题系统
- 深色/浅色模式
- 级联主题（应用级和工作区级覆盖）
- 主题持久化

## NFR-5：可扩展性

### NFR-5.1 会话管理
- 并发会话无硬性上限
- JSONL 仅追加格式，确保会话高效增长
- 长会话接近上下文限制时自动压缩

### NFR-5.2 来源管理
- 每个工作区来源数量不限
- 来源类型：MCP、API、本地
- 动态添加来源，无需重启

### NFR-5.3 工作区隔离
- 每个工作区拥有独立的设置、来源、技能、会话和自动化
- 工作区数据存储在 `~/.polo-ai/workspaces/{id}/`

## NFR-6：可维护性

### NFR-6.1 代码组织
- 单仓结构，包边界清晰
- 共享类型层（`@polo-ai/core`）确保跨包一致性
- 业务逻辑隔离在 `@polo-ai/shared` 中
- 服务器基础设施在 `@polo-ai/server-core` 中

### NFR-6.2 类型安全
- 全面使用 TypeScript（严格模式）
- 使用 Zod 模式进行运行时验证
- CI 中强制类型检查

### NFR-6.3 测试
- Bun 测试框架
- 集成测试（CLI --validate-server：21 步测试）
- CI 中的类型检查
- i18n 验证（排序、对等性、覆盖率）
- Lint 检查（IPC 发送、工具名称检查、ESLint）
